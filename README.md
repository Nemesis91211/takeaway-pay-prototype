# 外卖订单助手

原生微信小程序前端原型：展示一笔餐饮订单、倒计时和到期取消状态，并支持将携带相同到期时间的页面分享给微信好友。

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择“导入项目”。
2. 目录选择本项目根目录：`D:\workCode\takeaway-pay-prototype`。
3. 项目会使用已配置的 AppID；确认后编译即可。
4. 客户代付页必须通过管理员或代理人生成的分享链接打开；未携带有效订单 Token 时会显示“订单链接无效”。分享卡片会优先使用本地 Canvas 绘制的当前倒计时；Canvas 不可用时自动使用内置静态封面。

## 验证到期状态

在开发者工具中添加编译模式，页面路径填写 `pages/index/index`，启动参数填写有效订单 Token，例如：

```text
token=你的订单分享Token
```

编译后页面会从云数据库读取对应订单；过期订单显示取消状态，无效 Token 显示链接无效。未配置云环境时只能读取本地缓存中的订单。

## 可复用的主题结构

- `miniprogram/config/platforms.js`：各平台的主题色和文案入口。新增平台只需增加一项配置。
- `miniprogram/services/order.js`：订单默认数据、到期时间与倒计时计算。
- 分享路径携带 `expiresAt` 和 `platform`，接收者会使用同一截止时间。

当前项目不接入真实支付、退款或自动打款；支付按钮和回调位置保留为占位。订单、付款审核、余额流水、提现审核和代理人资料已接入 `takeawayApi` 云函数与云数据库，云环境配置和部署步骤见 [`cloudfunctions/takeawayApi/README.md`](cloudfunctions/takeawayApi/README.md)。

登录功能本轮仅预留接口和数据字段，不启用真实登录。若 `envList.js` 留空，将使用开发者工具关联的默认云环境；如果没有可用云环境或云函数调用失败，程序会明确降级到本地缓存，不能视为生产数据库模式。
